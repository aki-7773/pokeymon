📖 About This Project

The Pokémon Database is a comprehensive web application that provides detailed information about all Pokémon from Generation 1 to 9. It was created as a school project to demonstrate modern web development techniques using Python, Bottle framework, and the official PokeAPI.

This website features a complete Pokédex with stats, abilities, evolutions, Mega Evolutions, Gigantamax forms, regional variants, and much more!
